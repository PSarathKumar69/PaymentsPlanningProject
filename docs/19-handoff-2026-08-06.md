## How this project actually gets worked on (important, don't skip)

Sarath does not run Claude Code himself in this Cowork session — the
established pattern this whole project has used:

1. Sarath describes a problem or asks a question here (Cowork/Claude
   Desktop).
2. Claude (this assistant) either (a) makes small, safe, direct edits
   itself when the change is low-risk and Sarath says so explicitly
   ("do this from here, no need to test"), or (b) researches the codebase
   and writes a precise, self-contained prompt for Sarath's own separate
   Claude Code session to execute — saved to the outputs folder AND pasted
   verbatim in chat.
3. Sarath runs that prompt in his own Claude Code session (a different
   tool/process, not this one) and pastes the execution report back here.
4. **Claude independently verifies every claim in that report against the
   real filesystem/DB/code/tests before accepting it — never take an
   execution report at face value.** This has repeatedly caught real
   inaccuracies (miscounted test totals, misattributed fixes, and, most
   seriously, the open DB incident below) — keep doing this, it's not
   optional diligence, it's caught real problems every time it's been done.
